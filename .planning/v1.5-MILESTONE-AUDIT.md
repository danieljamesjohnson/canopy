## Cross-Phase Integration — 0 blockers

Five of six phases rebuilt the **same surface** (`lib/screens/today/`), each layering onto or
replacing the last. The integration risk here was never "do the phases talk to each other" — it was
"did a later phase quietly break an earlier phase's delivered requirement?" Checked against the
code, not the summaries:

**The single-detector invariant holds.** `resolveNowState` has exactly one definition
(`now_state.dart:117`) and one call site (`today_screen.dart:1129`). No file outside
`timeline_geometry.dart` performs its own minute→pixel arithmetic. This is the invariant the
milestone spent the most effort establishing — Phase 22 eliminated parallel detectors and a code
review caught a third — and it survived four subsequent phases.

**NOW-01 survived Phase 26 deleting its widget.** Phase 26 removed `NowMarkerRow` outright and
replaced it with `NowLineOverlay`. Judged a **mechanism swap, not a regression**: the requirement
text ("a visible now-marker at the current clock position") is satisfied by a strictly stronger
implementation — the overlay renders in *every* `NowState` including `Active`, whereas Phase 24 had
to suppress it mid-chunk because a boundary-positioned marker would have been mildly false. Phase 26
removed the reason the suppression existed rather than working around it. NOW-02's staleness guard
is intact at `timeline.dart:81-87`.

**Phase 25's DevClock still reaches the newest surface.** The plausible regression here was Phase 26
introducing a `DateTime.now()` that bypasses the injectable clock, silently breaking time-travel for
the very surface it was built to test. Verified clean: zero `DateTime.now()` hits in
`lib/screens/today/` outside doc comments; `TimelineGeometry.forDay` takes `nowMinutes` as a plain
`int`.

**Phase 21's engine work is untouched** — the only part of the milestone not on the rebuilt surface.
Mood tables still wired; no forbidden "behind" copy anywhere (the two textual hits are doc comments
*forbidding* it).

**All five E2E flows trace clean:** cold launch → check-in → proportional day; mid-day live row with
countdown and in-span now-line; complete-early → break absorbs reclaimed time; notification tap →
unified screen; DevClock offset → every surface agrees.

## Process findings — worth recording

This milestone shipped **two defects behind green tests**, both in Phase 26, and both with the same
shape: *an assertion that could not fail.*

1. A regression test asserted non-collision against `ChunkCard` when the defect lived in
   `LiveRowCard` — a different widget, because the live row is full-bleed and has no gutter. Green
   from the start against a live bug; the defect was reported to Dan as fixed when it wasn't.
2. The hour-axis test asserted widget *count* and label *text*, never a painted rect. The first and
   last hour label were sheared on every render, and the now-line shared the root cause — clipping at
   exactly `PreStart` and `DayComplete`, the two states where nothing else locates "now". That one
   was a real CAL-02 failure at the range edges.

Manual checking missed the first too: the verification screenshot happened to land on a *break* live
row, whose shorter content left the title clear. Coincidence read as coverage.

**Corrective practice adopted mid-phase:** from 26-09 onward, every regression test had to be
**observed RED against the unfixed code** before acceptance. That is how G-04 and G-05 were closed
properly. Recommended as standing practice for v1.6.

**What worked:** Phase 25's DevClock paid for itself immediately. G-03 and G-05 are both only visible
in states a fresh profile never generates — without a clock offset they would have shipped. Building
the test harness as its own phase, one phase before the phase that needed it, was the right call.
