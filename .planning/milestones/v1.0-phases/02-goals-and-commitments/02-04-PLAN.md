**commitments_screen.dart** — `CommitmentsScreen extends StatefulWidget`:
- `initState`: `WidgetsBinding.instance.addPostFrameCallback((_) => context.read<CommitmentsNotifier>().loadBlocks())`
- Build: `Scaffold(appBar: AppBar(title: Text('Commitments')), body: Consumer<CommitmentsNotifier>(builder: (ctx, notifier, _) => notifier.blocks.isEmpty ? _emptyState() : ListView.builder(...)), floatingActionButton: FloatingActionButton.extended(onPressed: _openAddSheet, icon: Icon(Icons.add), label: Text('Add commitment')))`
- ListView item: a Card showing a Row with: color swatch (16x16 circle using CommitmentBlock.color), 12dp gap, Expanded Column (name in titleMedium, formatted days+time in bodySmall), trailing IconButton(Icons.delete_outline, onPressed: () => _confirmDelete(ctx, block))
- `_commitmentCardSubtitle(CommitmentBlock block)` formats: `'${_formatDays(block.daysOfWeek)} · ${_formatTimeRange(block.startMinutes, block.endMinutes)}'`
- `_formatDays`: maps ISO day ints to abbreviations (1=Mon, 2=Tue, ..., 7=Sun), joins with comma. If all 5 weekdays (1-5): "Mon–Fri". If all 7: "Daily". Otherwise: comma-separated abbreviations.
- `_formatTimeRange(int start, int end)`: converts minutes to "9am", "5pm" format (use intl or manual: hour = minutes ~/ 60, minute = minutes % 60; if minute == 0: '${12-hour}am/pm' else '${12-hour}:${minute.toString().padLeft(2,'0')}am/pm'; handle noon=12pm, midnight=12am)
- `_confirmDelete`: show `showDialog` with AlertDialog ("Delete commitment?" + block.name, Cancel + Delete buttons). On confirm: `context.read<CommitmentsNotifier>().deleteBlock(block.id)`
- `_openAddSheet(context, [CommitmentBlock? block])`: `showModalBottomSheet(isScrollControlled: true, useSafeArea: true, builder: (ctx) => DraggableScrollableSheet(initialChildSize: 0.65, minChildSize: 0.4, maxChildSize: 1.0, expand: false, snap: true, snapSizes: [0.65, 1.0], builder: (ctx, sc) => CommitmentFormSheet(scrollController: sc, block: block)))`
- Tap on a card row (not delete button) calls `_openAddSheet(context, block)` for editing
- Empty state: centered Column with Icon(Icons.work_outline, size: 64) + "No commitments yet" + "Add your regular jobs, classes, or appointments" subtext

**commitment_form_sheet.dart** — `CommitmentFormSheet extends StatefulWidget`:
- Constructor: `const CommitmentFormSheet({super.key, required this.scrollController, this.block})`
- State: `_nameController`, `_selectedDays` (Set<int>), `_startMinutes` (int, default 9*60=540), `_endMinutes` (int, default 17*60=1020), `_color` (String, default '#607D8B')
- `initState`: if `widget.block != null`, populate all fields from existing block
- Build: `SingleChildScrollView(controller: widget.scrollController, child: Padding(padding: EdgeInsets.fromLTRB(16, 8, 16, 32) + MediaQuery.viewInsetsOf(context) for keyboard, child: Column([drag indicator, title, name field, SizedBox(16), day chips section, SizedBox(16), time row, SizedBox(24), save row])))`
- Drag indicator: `Center(child: Container(width: 40, height: 4, decoration: BoxDecoration(color: colorScheme.outline, borderRadius: BorderRadius.circular(2))))`
- Name field: `TextField(controller: _nameController, decoration: InputDecoration(labelText: 'Name', hintText: 'e.g. Work, Class, Gym'))`
- Day chips row: `Row(mainAxisAlignment: MainAxisAlignment.spaceBetween, children: List.generate(7, (i) { final day = i + 1; return FilterChip(label: Text(['M','T','W','T','F','S','S'][i]), selected: _selectedDays.contains(day), onSelected: (sel) => setState(() { sel ? _selectedDays.add(day) : _selectedDays.remove(day); })); }))` — wrap in a `Wrap` instead of Row if chips overflow narrow screens
- Time row: `Row(children: [Expanded(_timeTile('Start', _startMinutes, (v) => setState(() => _startMinutes = v))), SizedBox(width: 16), Expanded(_timeTile('End', _endMinutes, (v) => setState(() => _endMinutes = v)))])`
- `_timeTile(label, minutes, onSet)`: InkWell → `showTimePicker(context: context, initialTime: TimeOfDay(hour: minutes ~/ 60, minute: minutes % 60))` → if result != null call onSet(result.hour * 60 + result.minute). Display as `_formatTimeRange` of single time.
- Save button disabled if `_nameController.text.trim().isEmpty || _selectedDays.isEmpty`
- `_save()`: create/update CommitmentBlock with UUID (new for Add, existing id for Edit), call `context.read<CommitmentsNotifier>().saveBlock(block)`, `Navigator.pop()`
- CommitmentBlock constructor from Phase 1: `CommitmentBlock(id: widget.block?.id, name: ..., daysOfWeek: _selectedDays.toList()..sort(), startMinutes: _startMinutes, endMinutes: _endMinutes, color: _color)`
