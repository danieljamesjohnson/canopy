Build method: `Scaffold` with AppBar (title "Goals", actions: [PopupMenuButton with item "View archived" → navigates to `/goals/archived`]), body: `Consumer<GoalsNotifier>` wrapping a `CustomScrollView`.

CustomScrollView slivers:
- If all three groups empty: `SliverFillRemaining(child: _EmptyState())` — empty state shows centered icon + "No goals yet" text + "Add your first goal" subtext
- For each non-empty group (timeTarget → "Regular time", outcome → "Working toward", habit → "Daily habits"):
  - `SliverToBoxAdapter(child: Padding(padding: EdgeInsets.fromLTRB(16, 16, 16, 4), child: Text(header, style: titleSmall + color: colorScheme.primary)))`
  - `SliverToBoxAdapter(child: ReorderableListView.builder(shrinkWrap: true, physics: NeverScrollableScrollPhysics(), buildDefaultDragHandles: false, itemCount: group.length, itemBuilder: (ctx, i) => GoalCard(key: ValueKey(group[i].id), goal: group[i], onTap: () => _openEditSheet(ctx, group[i]), trailing: ReorderableDelayedDragStartListener(index: i, child: Padding(padding: EdgeInsets.symmetric(horizontal: 8), child: Icon(Icons.drag_handle, color: colorScheme.outline)))), onReorder: (old, newIdx) => context.read<GoalsNotifier>().reorder(type, old, newIdx)))`
