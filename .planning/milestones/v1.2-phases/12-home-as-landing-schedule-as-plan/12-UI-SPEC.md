## Spacing Scale

Flutter uses logical pixels. The 8-point scale maps directly (1dp ≈ 1 logical pixel in Flutter).

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon-to-label gaps, color bar width, divider thickness |
| sm | 8dp | Compact element spacing, SizedBox gaps within rows |
| md | 16dp | Default padding (card content, screen horizontal padding) |
| lg | 24dp | Section vertical padding, empty-state internal gaps |
| xl | 32dp | Empty-state horizontal margins |
| 2xl | 48dp | Compact break card height (existing short-break card height) |
| 3xl | 64dp | Empty-state icon size |

Exceptions:
- Touch targets: minimum 44dp height for all tappable rows (WCAG 2.5.5). Chunk action buttons must be at least 44dp tall.
- Left color bar on chunk cards: 4dp wide (multiple of 4, within rendering tolerance for a thin bar). The existing `chunk_card.dart` renders this at 5dp; this phase standardizes it to 4dp. Implementation should render the color bar at 4dp.
- Drag handle in bottom sheets: 32dp wide × 4dp tall (existing `chunk_detail_sheet.dart` convention — retain).
- Short break card height: 48dp (existing convention — retain).
- Card border radius: 12dp (existing `RoundedRectangleBorder(borderRadius: BorderRadius.circular(12))` — retain).
- Bottom sheet top radius: 16dp (existing `BorderRadius.vertical(top: Radius.circular(16))` — retain).

## Typography

All sizes are sp (scale-independent pixels), which Flutter treats as `fontSize` in `TextStyle`. These map to the existing Material 3 text theme roles the codebase already uses.

| Role | Flutter TextTheme Role | Size | Weight | Line Height |
|------|----------------------|------|--------|-------------|
| Heading | `titleMedium` | 16sp | w600 (semibold) | 1.4 |
| Body | `bodyMedium` | 14sp | w400 (regular) | 1.5 |
| Label | `bodySmall` / `labelMedium` | 12sp | w400 (regular) | 1.4 |
| Display | `titleLarge` | 22sp | w400 (regular) | 1.2 |

Usage rules:
- Chunk goal name (primary title): `titleMedium` at w600.
- Clock time string (e.g. "9:25 AM – 9:50 AM"): `bodySmall` at w400, `onSurfaceVariant` color.
- Rationale secondary text: `bodySmall` at w400, `onSurfaceVariant` color.
- "Now" / "Next" section labels: `labelMedium` at w400, `onSurfaceVariant` color, letterSpacing 0.8 (mirrors existing "Up next" label convention in `home_screen.dart`).
- Action button labels (Complete / Skip): `labelLarge` weight as provided by the button widget itself — do not override.
- Empty state heading: `titleLarge` at w400.
- Empty state body: `bodyMedium` at w400, `onSurfaceVariant` color.

## Color

The app uses `ColorScheme.fromSeed` driven by `ThemeNotifier` (mood seed or pre-check-in curious seed). All color references below use semantic `ColorScheme` roles so they stay correct across mood transitions.

| Role | ColorScheme Token | Mood-Agnostic Fallback | Usage |
|------|------------------|----------------------|-------|
| Dominant (60%) | `colorScheme.surface` | Material 3 surface | Screen backgrounds, scaffold body |
| Secondary (30%) | `colorScheme.surfaceContainerHighest` | Light grey | Cards (`Card` widget default), break card backgrounds |
| Accent (10%) | `colorScheme.primary` | Seed-derived primary | Reserved for: goal color bar, "now" marker dot/ring, filled action button (Complete), BreathingPulseCta shadow |
| Destructive | `colorScheme.error` | Material 3 error red | Skip action text/border, Defer to later text color |

Accent reserved for: left-edge goal color bar on chunk cards, the "now" marker visual indicator on the schedule, the FilledButton for "Mark complete", and the BreathingPulseCta pulse shadow on the empty-state CTA. Never applied to generic text, dividers, or navigation elements.

Swipe gesture backgrounds (existing — do not change):
- Swipe-right (complete): `Colors.green.shade400` background with white `Icons.check_circle`.
- Swipe-left (skip): `Colors.orange.shade300` background with white `Icons.arrow_forward`.

Completed-chunk state: opacity 0.5 applied to card content (existing `contentOpacity` convention). Left bar desaturates to `Colors.grey.shade400`.

Break card background: `colorScheme.surfaceContainerHighest.withValues(alpha: 0.5)` (existing short-break convention — retain for long-break cards too).

### 4. ChunkCard (modified: `lib/screens/schedule/widgets/chunk_card.dart`)

Clock time row replaces or augments the existing secondary text logic:


## Clock Time Contract

**Problem solved:** The dogfood identified that discretionary chunks showed "5x/week" (the goal's frequency metadata) instead of a clock time. The raw `rationale` string carried the frequency label, not a schedule time.

**Source of truth for start times:**
- Commitment chunks: `chunk.anchoredStartMinutes` (always set).
- Discretionary chunks: `chunk.syntheticStartMinutes` (set by `ScheduleGeneratorService` during generation, transient — not persisted to Hive).

**New persisted field needed:** `syntheticStartMinutes` is currently a transient in-memory field (not a `@HiveField`). For the clock time display to work after an app restart, `syntheticStartMinutes` must be persisted. Add it as `@HiveField(10)` to `ScheduledChunk` with a migration (schemaVersion 6).

**Display format:** `_formatTimeRange(int startMin, int endMin)` → e.g. `"9:25 AM – 9:50 AM"`.

Fallback: if `displayStartMinutes` is null (edge case for legacy chunks without field), show duration only (`"25 min"`).

**Unified accessor:** Add a getter `int? get displayStartMinutes => anchoredStartMinutes ?? syntheticStartMinutes` to `ScheduledChunk`. All UI reads this one getter.

## Chunk Action Contract

**Problem solved:** The dogfood identified that the unlabeled circle icon was an unclear affordance. The hover-only desktop overlay is invisible on touch.

**Decision:** Replace hover-gated icon buttons with always-visible compact labeled buttons on both touch and mouse surfaces (SCHED-03).

**On unresolved work chunks (both Home ActiveChunkCard and ScheduleScreen ChunkCard):**

Two always-visible action controls in the card trailing area:

| Control | Widget | Icon | Label | Width |
|---------|--------|------|-------|-------|
| Complete | `FilledButton.icon` | `Icons.check_circle_outline` | "Complete" | intrinsic |
| Skip | `OutlinedButton.icon` | `Icons.skip_next_outlined` | "Skip" | intrinsic |

Both use `visualDensity: VisualDensity.compact` to limit vertical footprint. Minimum tap target 44dp.

**On resolved work chunks:** Show status icon only (`Icons.check_circle` green for complete, `Icons.arrow_forward` onSurfaceVariant for skipped) — no action buttons. Opacity 0.5 applied to card content.

**Break cards:** No action controls. Retain existing compact (shortBreak) and full-height (longBreak) visual treatment.

**Hover behavior (desktop):** Remove the `MouseRegion` + `AnimatedOpacity` hover overlay pattern from `_HoverableChunkContent`. The always-visible buttons make it redundant. `MouseRegion` may be retained for cursor change only (pointer cursor on hover) without hiding/revealing any content.

**Swipe gestures (touch):** Retain existing `SwipeableChunkCard` / `Dismissible` swipe-right-complete, swipe-left-skip pattern. The always-visible buttons and swipe gestures are orthogonal and coexist.

**Detail sheet:** `ChunkDetailSheet` actions ("Mark complete", "Skip chunk", "Defer to later") are unchanged. The sheet remains the entry point for Defer.

| Trigger | Destination | Method |

## Accessibility Contract

- All action buttons ("Complete", "Skip") must have `tooltip` strings matching their label text.
- "Now" marker is decorative — no semantic role required (`ExcludeSemantics` wrapper acceptable).
- Clock time strings must be in a format screen readers speak naturally: "9 colon 25 AM dash 9 colon 50 AM" is acceptable; Flutter's default `Text` widget accessibility passes the string as-is.
- Minimum touch target: 44dp for all tappable controls (WCAG 2.5.5 / Material 3 recommendation).
- `BreathingPulseCta`: existing `_animationsDisabled` guard via `accessibilityFeatures.disableAnimations` — retain.
- Color is never the sole distinguishing factor for chunk state: completed chunks use both desaturation (opacity) AND the `Icons.check_circle` icon; skipped chunks use `Icons.arrow_forward` icon. Both pass the "not color only" rule.

## Adaptive Layout Contract

The existing `ResponsiveShell` breakpoint (720dp) and two-column layout are unchanged.

On screens ≥ 720dp:
- `ActiveChunkCard` action row renders inline as specified (full-width FilledButton and OutlinedButton). No truncation at this width.
- `NowMarker` divider spans the full card-list width (same as mobile).

On screens < 720dp (bottom nav, single column):
- `ActiveChunkCard` action buttons stack if intrinsic widths overflow; use `Expanded` with `Row` for the button pair so they share width equally.
