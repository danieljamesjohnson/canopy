## Locked planner decisions this plan implements

**PD-12 — suppression is deleted, not relocated.** There is no `nowState is! Active` guard, no
`hasLiveRow` branch, and no "should we show the line" condition anywhere in this plan. The
rendered range is defined by `TimelineGeometry.forDay` as a `min`/`max` against `nowMinutes`
itself, so `nowMinutes` is inside the rendered span by construction in every state. The line is
therefore always representable, which is the literal mechanism by which CAL-02 supersedes Phase
24's suppression rule.

**PD-13 — `Semantics` sits OUTSIDE `IgnorePointer`, not inside it.** Modern Flutter's
`IgnorePointer` removes its subtree from the semantics tree as well as from hit testing. Placing
the labelled node inside it would silently delete the 'Now — <time>' announcement — a
regression the Phase 24 review (24-REVIEW.md WR-01) already caught once in a different form.
Order at the call site is `Positioned > Semantics(excludeSemantics: true) > IgnorePointer >
NowLineOverlay`.

**PD-14 — tick cadence is untouched.** The all-day ticker stays at 1 minute; the 1-second ticker
stays scoped to the final minute of the current activity (`today_screen.dart`'s own doc comment:
"D-01 forbids a blanket 1-second ticker on a screen the user leaves open all day"). At
`kPixelsPerMinute = 5.5`, a minute tick advances the line 5.5px. CAL-02's "continuously
positioned" describes the position formula being valid at every instant, not an animation frame
rate. Do not add an all-day faster ticker; doing so reopens a battery tradeoff Phase 23 already
fought and won, for a cosmetic glide nothing asked for.
