<objective>
Replace Home's "first unresolved chunk" Now/Next selection with a time-anchored
state machine. The new logic picks the chunk whose clock window
`[displayStartMinutes, displayStartMinutes + durationMinutes)` contains the current
wall-clock time, and renders distinct pre-start and day-complete states when no
chunk is active. A 1-minute timer keeps the Now zone fresh as time passes.

Implements NOW-01 (Now reflects the current clock window, not the first unresolved
chunk; at 6pm the 8am chunk is no longer Now) and NOW-02 (clear pre-start /
day-complete states instead of a stale Now).

Purpose: The current Home Now zone lies — at 6pm with nothing checked off it shows
the 8am chunk as "Now." This phase makes Home tell the truth about where the user is
in their day, matching the v1.3 "An Honest Day" milestone.

Output:
- `resolveNowState(...)` pure top-level function + `NowState` sealed hierarchy in `home_screen.dart`
- 1-minute `Timer.periodic` + `WidgetsBindingObserver` lifecycle on `_HomeScreenState`
- pre-start and day-complete inline states
- New pure-unit + widget test file `home_screen_now_state_test.dart`
- Migrated assertions in `active_chunk_card_test.dart`
</objective>
