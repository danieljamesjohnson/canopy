<objective>
Close the streak divergence window: at schedule generation time, recompute and persist `goal.streakCount` for every active habit goal so the value the goal card displays always matches the engine's canonical `computeStreak()` result (per success criterion SC2, requirement STREAK-01).

Purpose: The engine computes the authoritative streak internally to build the rationale string but never writes it back. The persisted `streakCount` only updates when the user marks a chunk complete/skipped/deferred, so a cold launch the day after a completion shows a stale streak. This plan adds a generation-time write-back that reuses the existing static streak formula.

Output: A guarded write-back loop in `ScheduleNotifier.generateToday()` plus a notifier-level test that proves the persisted streak is synced (not left stale) through the generation path.
</objective>
