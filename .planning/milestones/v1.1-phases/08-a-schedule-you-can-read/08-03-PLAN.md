<objective>
Ship the minimal companion focus mode (READ-04).

Add a `/focus` full-screen route outside the StatefulShellRoute (no bottom nav, mirroring `/summary`), receiving a `chunkId` via `extra`. `FocusScreen` is a StatefulWidget highlighting the target chunk's goal with an optional 25-minute `Timer.periodic` countdown the user can start, pause, or skip. On timer completion or an explicit "Done early", it calls `ScheduleNotifier.markComplete(chunkId)` and surfaces a break suggestion derived from the next chunk in the schedule. The timer is cancelled in `dispose()` to prevent a setState-after-dispose leak. Auto-advance and the closed completion loop remain deferred to Phase 10.

Entry points: the "Start focus" button already in `ChunkDetailSheet` (Plan 02) plus a schedule-screen affordance passing the first unresolved work chunk's id.

Purpose: gives users a calm, single-chunk focus companion — the last legibility surface of the phase.
Output: new focus_screen.dart, /focus route in router.dart, schedule-screen entry affordance. Turns the focus_screen Wave 0 stub green.
</objective>
