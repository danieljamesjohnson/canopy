Make the schedule legible (READ-01) and actionable (READ-03).

READ-03: add a `ChunkDetailSheet` opened via `showModalBottomSheet` on tap of an unresolved work chunk, showing goal name, rationale, and Complete / Skip / Defer actions (plus a "Start focus" entry point whose target route is wired in Plan 03). Add a minimal `markDeferred` notifier method that sets `isDeferred=true` + `isSkipped=true` so the existing skipped-section partition logic moves the chunk without further screen changes (full cross-day carryover is Phase 10).

Purpose: this is the headline legibility fix — users see goal names instead of "Habit"/"Outcome goal", and get a discoverable explicit action path.
