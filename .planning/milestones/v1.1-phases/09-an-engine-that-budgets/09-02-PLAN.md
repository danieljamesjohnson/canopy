| T-09-06A | Tampering | SegmentedButton value space | accept | The control can only emit 0.25 / 0.5 / 0.75 (fixed segments). No invalid `priorityWeight` is reachable through the UI. |

| T-09-SC | Tampering | npm/pip/cargo installs | accept | Zero new packages; SegmentedButton is a Material 3 built-in. No legitimacy surface. |

Proportional and honest: this is a single built-in widget over a fixed three-value enum-like space; the only real risk is an empty selection set, mitigated by the null-coalesce.
