<objective>
Build the row-model and widget half of Phase 24: a fourth `TimelineRow` subtype that carries the
current clock position, the suppression/insertion rules that place it, the NOW-02 guard that stops
a leading "Free until" row describing a closed window, and the quiet `NowMarker` widget that renders
it — plus the pure unit tests and widget tests that prove all of it.

**Locked decisions this plan implements** (from `24-CONTEXT.md` → `## Implementation Decisions` →
`### Locked`; referenced as D-01/D-02 throughout for traceability):

- **D-01 — the marker is a position, not a second detector.** Its clock position is passed in as an
  `int`; `buildTimeline` must NEVER read a clock and must NEVER re-derive which activity is current.
  `timeline.dart`'s INVARIANT 1 survives intact. This is the single-detector rule Phase 17
  established, Phase 22 spent a plan enforcing, and a Phase 22 code review extended.
- **D-02 — show the marker when it adds information.** Suppress for `Active` (`LiveRowCard` already
  answers "where am I", and the marker's boundary position would be slightly false mid-chunk); show
  for `PreStart`, `GapBeforeNext`, `Overdue`, `DayComplete`. Suppression is keyed on
  `nowState is! Active` specifically — NOT on "does the list contain an `isLive` row", because
  `Overdue` also sets `isLive` and `Overdue` MUST show the marker.

Purpose: Dan could not locate "now" in his own timeline (`24-evidence-dan-drop.png`, a
`GapBeforeNext` screen at 12:34 still showing "Free until 11:45 AM"). This plan builds the
mechanism; plan 24-02 wires it to the screen.

Output: `NowMarkerRow`, `NowMarker`, `minutesOfDay`, an optional `nowMinutes` parameter, and green
unit + widget tests.
</objective>
