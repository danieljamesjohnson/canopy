<objective>
Write every test that defines "a break you can see", prove the five behavioural ones RED, and land
the minimum scaffold in `lib/` that lets them compile without implementing the behaviour.

Purpose: this codebase's binding carry-forward invariant is that **a regression test is only real
if it was observed failing against the unfixed code** — v1.5 shipped two defects behind green tests
that could not fail, and Phase 28 closed that hole structurally by writing all tests in wave 1 and
letting wave 2 touch only `lib/`. This plan reproduces that structure for a UI change.

The one adaptation: a test that names `ChunkCardDensity.subCompact` cannot even *compile* against
today's tree, and a compile error is not a RED test — it proves nothing about behaviour. So this
plan lands a deliberately inert scaffold first (PD-29-01), then writes tests that fail because the
behaviour is missing, not because a symbol is.

Output: `chunk_card.dart` and `timeline_geometry.dart` carrying an inert `subCompact` tier, eight
new tests, and `29-RED-subcompact.txt` holding the proof that five of them fail for the right
reason.

**Intermediate state notice:** this plan deliberately leaves the repository with a failing test
suite. Plan 29-02 turns it green by touching `lib/` only. Do not wire the break branch or the
screen ternary here, and do not weaken an assertion to make it pass.
</objective>
