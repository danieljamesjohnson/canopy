Two edits. Nothing else in `lib/`, and nothing at all in `test/`.

**Edit 1 — `ChunkCard._buildBreak`, `chunk_card.dart` (D-01).** Insert an early return
`if (density == ChunkCardDensity.subCompact)` returning `_SubCompactRow` with `label: title` and
`semanticsLabel: '$title, ${chunk.durationMinutes} min'`. Place it **above** the existing
`if (density == ChunkCardDensity.compact)` check.

Branch order is the whole correctness of this edit and gets no compiler protection: this is an
`if`-chain, not a `switch`, so if the new branch is placed after `compact`'s — or omitted — the
build still succeeds and `subCompact` silently falls through to the `detailed`/`full` treatment
with no warning. That is RESEARCH Pitfall 1's named "silent failure mode". Add a comment stating
the ordering requirement so a future reorganisation does not undo it.

The semantics label is locked copy from `29-UI-SPEC.md` § "Copywriting Contract" —
`'Short break, 5 min'` for the reachable case. Do not restyle it, do not add the word "break" twice,
do not append a time range.

**Edit 2 — `today_screen.dart`'s break density selection (D-01).** Replace the two-band break
ternary at lines 789-792 with the three-band form `29-UI-SPEC.md` item 4 spells out: `full` at or
above `kFullBreakMinHeight`, otherwise `compact` at or above `kSubCompactBreakMinHeight`, otherwise
`subCompact`. Import the constant from `timeline_geometry.dart` if it is not already in scope (it
is — the file already reads `kFullBreakMinHeight` and `kFullTierMinHeight` from there).

The work branch at lines 793-795 stays **byte-identical**. `29-UI-SPEC.md` § "Scope boundary" makes
this an explicit decision, not an oversight: work chunks have no reported defect and no measurement
evidence, and extending the tier to them would be untracked scope creep. The `_WorkChunkContent`
`subCompact` arm wave 1 added stays an unreachable documented fallback.

Do not touch the `Positioned` / `ClipRect` / `OverflowBox` / `TimelineRowTile` wrapper at lines
802-817. That wrapper is what makes SEEBREAK-02 true by construction — the slot is
`geometry.heightFor(start, chunk.durationMinutes)` before this phase, during it, and after it. The
new tier's job is to make the card's *natural* height already fit, so the safety net stops engaging
for breaks; the net itself stays in place unconditionally for every other row.

Add a short comment above the ternary naming the tier the current lattice actually reaches: a
5-minute break (20dp) always lands in the `subCompact` band, a 30-minute long break (120dp) always
lands in `full`, and the `compact` break band is unreachable under Phase 28's generator today —
kept because the rule is slot-height-driven, not chunk-type-driven, and a future cadence change
could reach it (`26-UI-SPEC.md`'s stated principle, restated in `29-UI-SPEC.md`'s tier table).

**Then run the targeted files, then the full suite.** Every one of wave 1's five RED-PROOF tests
