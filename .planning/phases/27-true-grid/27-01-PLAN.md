<objective>
Make `TimelineGeometry.yFor()` purely linear, and add the one test the suite has always been
missing so a regression can be caught rather than silently shipped.

Purpose: this is the actual defect (GRID-01). `yFor()` adds `liveExtraPx` once the minute passes
`liveEndMinutes`, so exactly one hour per day renders 372dp against every other hour's 240dp — but
only while a chunk is live. All 560 existing tests pass in both states, because they assert
`yFor()` against the same arithmetic the implementation performs. The deletion is one term; the
test that closes the hole is the substance.

Output: a branch-free `yFor()`, `kLiveRowReservedHeight` gone, `kCompactLiveMinHeight` added as an
explicitly UNMEASURED placeholder for wave 2 to compile against, and an equidistance test proven
red-then-green.
</objective>
