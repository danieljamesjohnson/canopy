# Phase 04 Plan 01: Swipe Completion Gestures + CompletionLog Integration

## Objective

Add swipe-to-complete (right) and swipe-to-skip (left) gestures to work chunk cards in the schedule screen. Wire gestures to ScheduleNotifier which updates ScheduledChunk flags and appends CompletionLog entries. Skipped chunks move to a collapsed "Skipped today" section at the bottom.

## Context

@.planning/phases/04-chunk-tracking-and-notifications/04-CONTEXT.md
@.planning/phases/03-schedule-generation-and-morning-check-in/03-CONTEXT.md

## Tasks

### Task 1: Add markComplete/markSkipped methods to ScheduleNotifier
`type="auto"`

Add two methods to `ScheduleNotifier` that:
1. Find the chunk by ID in `_todaySchedule.chunks`
2. Set `isCompleted = true` or `isSkipped = true` on the `ScheduledChunk`
3. Append a `CompletionLog` entry via `HiveCompletionLogRepository`
4. Save the updated `DailySchedule` back to the repository
5. Call `notifyListeners()`

The `CompletionLog` entry needs: `chunkId`, `goalId` (use `''` if null for break chunks, but only work chunks are swipeable so goalId should be present), `dateYmd` (today), `eventIndex`.

**Done criteria:** `ScheduleNotifier` has `markComplete(String chunkId)` and `markSkipped(String chunkId)` methods that compile without errors.

### Task 2: Wrap ChunkCard with Dismissible swipe gestures
`type="auto"`

In `schedule_screen.dart`, wrap each work chunk's `ChunkCard` with a `Dismissible` widget:
- Key: `ValueKey(chunk.id)`
- swipe right (start-to-end) → calls `scheduleNotifier.markComplete(chunk.id)` — background shows green with check icon
- swipe left (end-to-start) → calls `scheduleNotifier.markSkipped(chunk.id)` — background shows orange/amber with skip icon
- `confirmDismiss` returns `false` (card stays in list — Dismissible is used for gesture detection only, not removal)
- Break cards are NOT wrapped (no swipe on short/long breaks)
- Already-completed or already-skipped chunks are NOT wrapped (use `IgnorePointer` or skip the wrap)

**Done criteria:** Swiping right or left on a work chunk triggers the correct notifier method. Cards remain in position after swipe.

### Task 3: Add "Skipped today" collapsed section
`type="auto"`

In `schedule_screen.dart`, split the chunks list into active and skipped. Render:
1. Active chunks (not skipped) in the main `ListView`
2. An `ExpansionTile` at the bottom titled "Skipped today (N)" that contains the skipped chunks rendered as non-interactive `ChunkCard`s

The expansion tile is hidden when there are no skipped chunks.

**Done criteria:** Swiping left on a chunk causes it to disappear from the main list and appear in the collapsed "Skipped today" section at the bottom.

### Task 4: flutter analyze + tests pass
`type="auto"`

Run `flutter analyze` and `flutter test`. Fix any issues found.

**Done criteria:** Zero analyze issues. All existing tests pass.
