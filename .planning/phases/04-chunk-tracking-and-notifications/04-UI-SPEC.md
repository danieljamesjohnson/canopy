## Spacing Scale

Multiples of 4dp only. Flutter uses logical pixels (dp), not CSS px.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon gaps, between label and sub-label within a card |
| sm | 8dp | Spacing between card content elements; progress bar gap |
| md | 16dp | Default horizontal card margin; section padding; list padding |
| lg | 24dp | Vertical padding inside bottom sheets; button vertical padding area |
| xl | 32dp | Empty state vertical spacing between icon and heading |
| 2xl | 48dp | Acknowledgment screen element separation; end-of-day summary section gap |
| 3xl | 64dp | Not used in Phase 4 |

Exceptions:
- ChunkCard left color bar: 5dp width (existing — not changed)
- ShortBreak card height: 48dp fixed (existing — not changed)
- Swipe reveal background icon padding: 20dp left/right (Dismissible background)
- Touch targets for swipe reveal icons: minimum 44dp height (Dismissible fills card height)

## Typography

All roles map to Flutter Material 3 TextTheme. No custom font sizes or font families are
introduced in Phase 4. All sizes below are the Material 3 defaults for Roboto at medium
display density.

| Role | Flutter TextTheme Role | Size | Weight | Line Height |
|------|----------------------|------|--------|-------------|
| Body | `bodyMedium` | 14sp | 400 | 1.43 |
| Label / metadata | `bodySmall` | 12sp | 400 | 1.33 |
| Chunk title | `titleMedium` bold | 16sp | 700 | 1.5 |
| Section heading / summary stat | `titleLarge` bold | 22sp | 700 | 1.27 |

Declared weights used in Phase 4: **400 (regular)** and **700 (bold)**.
Weight 600 (semibold) is used only in `ScheduleProgressBar` label (pre-existing — not
introduced here).

## Color

Seed color: `Color(0xFF3D6B4F)` — forest green. Material 3 generates the full
`ColorScheme` from this seed.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `colorScheme.surface` | Screen backgrounds, Scaffold background |
| Secondary (30%) | `colorScheme.surfaceContainerHighest` | Cards (Material Card default elevation), bottom sheets, settings list tiles |

| Complete accent | `Colors.green.shade400` / `Colors.green.shade600` | Swipe-right reveal background; completed chunk check_circle icon only |

## Component Inventory

### 1. SwipeableChunkCard (new wrapper)

Wraps existing `ChunkCard` in a `Dismissible` widget.

**Swipe-right (complete) reveal background:**
- Full-height `Container`, `Colors.green.shade400`
- `Icons.check_circle` icon, `Colors.white`, size 28dp
- Icon alignment: `Alignment.centerLeft`, left padding 20dp

**Swipe-left (skip) reveal background:**
- Full-height `Container`, `Colors.orange.shade300`
- `Icons.arrow_forward` icon, `Colors.white`, size 28dp
- Icon alignment: `Alignment.centerRight`, right padding 20dp

**Gesture rules:**
- `DismissDirection.horizontal` for active work chunks
- `DismissDirection.none` for already-completed or already-skipped chunks (no re-swipe)
- `confirmDismiss` always returns `false` — card stays in list
- Break cards (`shortBreak`, `longBreak`): not wrapped in `Dismissible` — swipe disabled

**Haptic feedback:** `HapticFeedback.lightImpact()` on swipe confirmation (both directions).

**Undo affordance:** None in v1. The action is confirmed by the visual state change
(grey + check icon for complete, moved to skipped section for skip). No snackbar undo.

### 2. Skipped Section (ExpansionTile)

Location: bottom of `ScheduleScreen` ListView, below all active chunks.

**Collapsed state (default):**
- `ExpansionTile` title: "Skipped today (N)" — N = count of skipped chunks
- `bodySmall` text, `colorScheme.onSurfaceVariant`
- `Icons.expand_more` trailing icon (ExpansionTile default)
- Only visible when N > 0

**Expanded state:**
- Skipped `ChunkCard` items rendered at 50% opacity (visual parity with completed state)
- Left bar color: `Colors.grey.shade400` (same as completed bar — both are "resolved")
- No swipe gesture on skipped cards

### 3. End-of-Day Summary Screen (`/summary`)

Route: `GoRoute(path: '/summary')` outside `StatefulShellRoute` — no bottom nav.

**Entry point:** "View your day" option in `ScheduleScreen` AppBar overflow menu
(`PopupMenuButton`). The menu item is active only when 50%+ of work chunks are resolved
(completed or skipped). Before that threshold, it is hidden (not greyed out — hidden).

**Screen layout (single-scroll column):**

Section A — Hero stat:
- Large centered number: completed chunk count (`titleLarge` bold, 22sp, weight 700)
- Sub-label: "of N chunks complete" (`bodyMedium`, `onSurfaceVariant`)
- Vertical padding: 32dp above, 24dp below

Section B — Per-goal breakdown:
- `ListView` (shrinkWrap, non-scrolling inside outer scroll)
- One row per goal that had chunks today: goal color dot (12dp circle) + goal name +
  "X of Y" label right-aligned
- Row height: 48dp
- Section heading: "By goal" (`titleMedium` bold, 16sp, weight 700), 16dp top margin

Section C — Skipped count (only if skipped > 0):
- Single `Text` line: "N chunk(s) set aside today." (`bodyMedium`, `onSurfaceVariant`)
- 8dp top margin below per-goal list

Section D — Close action:
- Full-width `ElevatedButton`: "See you tomorrow"
- 32dp top margin, 16dp horizontal padding, 48dp bottom safe area padding
- On tap: `context.pop()` back to schedule

**Tone:** Celebratory, not evaluative. No "you missed" language. No completion percentage
shown (avoid implicit judgment on partial days).

### 4. Settings Screen (full replacement)

Route: existing `/settings` — replace stub with `ListView` of `ListTile` rows.

**AppBar:** title "Settings", standard Material 3 AppBar (no mood color tint).

**Section 1 — Notifications** (heading: "Notifications", `bodyMedium` weight 600):

Row 1 — Morning reminder:
- `ListTile` with `Icons.alarm` leading icon
- Title: "Morning reminder"
- Subtitle: current time formatted as "7:30 AM" (or "Off" if disabled)
- Trailing: `Switch` (on/off)
- On tile tap when enabled: `showTimePicker()` → updates `SettingsNotifier.morningNotificationMinutes`

Row 2 — Mid-day nudge:
- `ListTile` with `Icons.notifications_outlined` leading icon
- Title: "Mid-day nudge"
- Subtitle: "Opt-in reminder to check your schedule" when off; time string when on
- Trailing: `Switch` (default off — opt-in)
- On tile tap when enabled: `showTimePicker()` → updates `SettingsNotifier.midDayNudgeMinutes`

Row 3 — Notification note (Android only):
- `ListTile` with no leading icon, no trailing
- Subtitle only: "Reminders may arrive up to 15 minutes early due to device battery settings."
- `bodySmall`, `onSurfaceVariant`, 8dp top/bottom padding
- Only rendered on Android (use `Platform.isAndroid` guard)

**Section 2 — Data** (heading: "Data", `bodyMedium` weight 600):

Row 1 — Export data:
- `ListTile` with `Icons.download_outlined` leading icon
- Title: "Export data"
- Subtitle: "Download a JSON file of all your completion history"
- Trailing: `Icons.chevron_right` (no Switch)
- On tap: calls export service, shows `SnackBar("Preparing export...")` during operation,
  then triggers share sheet. On success: no additional confirmation needed (share sheet is
  the confirmation). On error: `SnackBar("Export failed. Try again.", duration: 4s)`.

**Section dividers:** `Divider` with 16dp indent between sections.

### 5. Web In-App Banner

Location: top of `ScheduleScreen` body (above progress bar and chunk list).

Condition: `kIsWeb && !scheduleNotifier.hasScheduleToday`

Implementation: `MaterialBanner` (Material 3 component, persistent until dismissed or
schedule is generated).

- Content text: "Start your morning check-in to build today's schedule."
- Action button: `TextButton` — label "Start check-in", navigates to `/schedule/checkin`
- Background: `colorScheme.primaryContainer`
- Text color: `colorScheme.onPrimaryContainer`
- No dismiss/close action (persistent until schedule generated)

## Interaction States

### ChunkCard states (work variant)

| State | Left bar | Content opacity | Trailing icon | Swipe |
|-------|----------|-----------------|---------------|-------|
| Active | Goal color | 1.0 | `radio_button_unchecked` (onSurfaceVariant) | Enabled |
| Completed | `Colors.grey.shade400` | 0.5 | `check_circle` (Colors.green.shade600) | Disabled (none) |
| Skipped | `Colors.grey.shade400` | 0.5 | `arrow_forward` (onSurfaceVariant) | Disabled (none) |

### Settings Switch states

Both notification switches follow Material 3 Switch defaults:
- Active track: `colorScheme.primary`
- Inactive track: `colorScheme.surfaceContainerHighest`
- Thumb: white

### Export button state

- Idle: full opacity, `Icons.chevron_right` trailing
- Loading: `CircularProgressIndicator` (size 20dp) replaces trailing icon; `ListTile` `onTap` set to null (non-tappable during export)

## Animation Contracts

|------------|-----------|----------|-------|

| Acknowledgment AnimatedSwitcher (existing) | Fade cross-dissolve | 300ms | — |

## Accessibility

- All `ListTile` rows in Settings have semantic labels via `Semantics` wrapper if the
  trailing widget is a `Switch` (the switch label must be readable as "Morning reminder,
  on/off")
- Swipe gestures on ChunkCards: the chunk detail bottom sheet (tap to open) provides a
  non-swipe path to mark complete or skip on desktop and for accessibility users
- `SnackBar` messages use `SnackBarBehavior.floating` so they do not obscure the bottom
  nav bar
- Minimum tap target for `ListTile` rows: 56dp height (Material 3 default)
