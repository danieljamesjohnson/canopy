<objective>
Give a skipped break a visible, legible, screen-readable state at all three density tiers,
reusing the exact resolved-state vocabulary a skipped work chunk already uses — implementing
D-31-04 without inventing a break-specific visual language and without growing any box.

Purpose: plan 31-01 made a break skippable. A break the user can skip but cannot see the
skipped-ness of is a state change with no feedback. Phase 29's `_SubCompactRow` has no
completed/skipped state at all, so the 20dp hairline — the very tier this phase exists for — is
the one that needs the new work.

Output: three tiers of skipped treatment, one new widget parameter, one new `Semantics` wrapper,
and the tests that pin all of it.
</objective>
