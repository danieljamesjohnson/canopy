# Phase 10 — UI Design Contract

> Visual and interaction contract for Phase 10: Close the Day.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** This phase adds exactly ONE new visual component (the end-of-day
> Home card) and ONE toggle row (evening reminder in Settings). All other surfaces
> in scope (EndOfDaySummaryScreen at `/summary`, the chunk detail sheet's Defer
> action) are already built and must be reused without redesign. This contract
> defines only the new surface; existing surfaces are called out as "reuse existing
> pattern — no new contract needed."

## Typography

All type roles use Flutter's `Theme.of(context).textTheme.*` — no custom font sizes
are hardcoded. The roles below map to Material 3 TextTheme tokens as used throughout
the existing codebase.

| Role | M3 TextTheme token | Approx size | Weight | Line Height |
|------|--------------------|-------------|--------|-------------|
| Card heading | `titleMedium` | ~16sp | w700 (bold) | 1.4 |
| Card body / subtitle | `bodySmall` | ~12sp | w400 (regular) | 1.4 |
| Label / section heading | `bodyMedium` w600 | ~14sp | w600 (semibold) | 1.0 |
| Button label | `labelLarge` (Material default) | ~14sp | w500 (medium) | 1.0 |

**Concrete rules for the end-of-day card:**
- Card heading text: `Theme.of(context).textTheme.titleMedium?.copyWith(fontWeight: FontWeight.bold)` — same as `ReviewBanner` title.
- Card subtitle text: `Theme.of(context).textTheme.bodySmall?.copyWith(color: colorScheme.onSurfaceVariant)` — same as `ReviewBanner` subtitle.
- Button label: standard `ElevatedButton` child `Text(...)` — inherits `labelLarge`.

**Source:** `review_banner.dart` lines 44, 57 (exact copyWith pattern); `home_screen.dart`
lines 116, 188 (bodySmall onSurfaceVariant pattern).

## Color

This project uses a dynamic `ColorScheme.fromSeed` driven by the user's daily mood
(ThemeNotifier). All color references below use semantic `ColorScheme` roles, not fixed
hex values. The mood-seed palette is locked (Phase 6):

| Mood | Seed hex |
|------|----------|
| 1 | `#4A6275` |
| 2 | `#5C7A8A` |
| 3 | `#4A8C7A` |
| 4 | `#7AAF6A` |
| 5 | `#E8C547` |
| Pre-check-in | `#7A8FA3` |

| Role | ColorScheme token | Usage in this phase |
|------|-------------------|---------------------|
| Dominant (60%) | `colorScheme.surface` | Page background behind card |
| Secondary (30%) | `colorScheme.primaryContainer` | End-of-day card background fill |
| Accent (10%) | `colorScheme.primary` | ElevatedButton fill inside card |
| On-container text | `colorScheme.onPrimaryContainer` | Card heading text |
| Muted text | `colorScheme.onSurfaceVariant` | Card subtitle, dismiss icon |
| Destructive | `colorScheme.error` | Not used in this phase |

**Accent reserved for:** the single `ElevatedButton` inside the end-of-day card
("Close the day" CTA). The dismiss `IconButton` uses `onSurfaceVariant` — it is
not an accent element.

**Card background:** `colorScheme.primaryContainer` — exact same token as `ReviewBanner`
(`review_banner.dart` line 22). This establishes visual continuity: the end-of-day
card belongs to the same "notice" family as the quarterly-review banner.

**Source:** `review_banner.dart` line 22 (`Theme.of(context).colorScheme.primaryContainer`);
`theme_notifier.dart` lines 56–62 (mood seed palette).

## Component Inventory

### NEW: EndOfDayCard (CLOSE-01)

A dismissible card pinned at the top of the Home screen's active-schedule view,
rendered in the same position as `ReviewBanner` (immediately after `ScheduleProgressBar`
and the mood row).

**Trigger conditions (OR logic):**
- Current local time is >= 18:00 (6pm), OR
- `resolvedCount / workChunkCount >= 0.5` where `resolvedCount = completed + skipped + deferred`.

**Card structure:**

```
[Card — colorScheme.primaryContainer — margin: horizontal 16, vertical 8]
  [Padding — vertical: 8]
    [Row — crossAxisAlignment: center]
      [Expanded]
        [Column — crossAxisAlignment: start]
          [Row]
            [Expanded]
              [Text — titleMedium bold] "How did today go?"
            [IconButton — Icons.close — onSurfaceVariant] → dismisses card
          [Text — bodySmall onSurfaceVariant] "X of Y chunks done"
      [Padding — right: 16, left: 8]
        [ElevatedButton] "Close the day" → context.push('/summary')
```

**Dismissed state:** When the user taps the close IconButton, the card disappears
for the remainder of the session. Dismissal is in-memory only (same pattern as
`_bannerDismissed` in `HomeScreen`) — the card reappears on next app launch if
the trigger condition is still true.

**Swipe-to-dismiss:** Wrap with `Dismissible` (same as `ReviewBanner`) with
`DismissDirection.horizontal`. On dismiss: call the same `setState(() => _eodCardDismissed = true)` pattern.

**Placement:** Insert immediately after the `ReviewBanner` conditional block in
`home_screen.dart` `build()`. If both the quarterly review banner and the end-of-day
card are active simultaneously, the quarterly review banner appears first (it is
higher urgency — user must act within a window). End-of-day card appears below it.

**Do NOT show the card when:** `scheduleNotifier.hasScheduleToday` is false (the
empty-state branch does not include this card).

### REUSE: Chunk Detail Sheet — Defer action (CLOSE-02)

Reuse existing pattern — no new contract needed.

The Defer action button in `ChunkDetailSheet` (built in Phase 8) is already present
with its visual treatment. This phase only wires `markDeferred` to log
`CompletionEvent.deferred` instead of `CompletionEvent.skipped`. No widget changes.

### REUSE: EndOfDaySummaryScreen at /summary (CLOSE-01)

Reuse existing pattern — no new contract needed.

`lib/screens/end_of_day/end_of_day_summary_screen.dart` is the destination the
end-of-day card routes to. Do not modify its layout, typography, or color. Phase 10
only makes it reachable via the new card.

### NEW: Evening Reminder toggle row in Settings (CLOSE-01)

One new `ListTile` added to `SettingsScreen` in the "Notifications" section, between
the mid-day nudge row and the Android battery note.

**Structure — mirror the mid-day nudge row exactly:**

```
[ListTile]
  leading: Icon(Icons.nights_stay_outlined)     // distinguishes from mid-day sun icon
  title: Text('Evening reminder')
  subtitle: Text(
    eveningEnabled ? _formatMinutes(1200) : 'Opt-in reminder to close your day',
  )
  trailing: Switch(value: eveningEnabled, onChanged: _handleEveningToggle)
  onTap: null                                   // no time-picker this phase (fixed 8pm)
```

**Icon choice:** `Icons.nights_stay_outlined` — communicates evening/night without
introducing a new icon family. Alternatives if `nights_stay_outlined` renders poorly:
`Icons.bedtime_outlined` or `Icons.wb_twilight`.

**No time picker:** The CONTEXT.md decision is a fixed default (8:00pm / 1200 minutes
from midnight) with no time-picker UI this phase. The `onTap` is therefore `null`.
The subtitle shows the fixed time when enabled.

**Source:** `settings_screen.dart` lines 122–163 (mid-day nudge row — exact structural
template).

## Copywriting Contract

| Element | Copy |
|---------|------|
| End-of-day card heading | "How did today go?" |
| End-of-day card subtitle | "X of Y chunks done" (computed at render time; e.g. "5 of 8 chunks done") |
| End-of-day card CTA button | "Close the day" |
| End-of-day card dismiss tooltip | "Dismiss" (tooltip on IconButton; screen-reader accessible) |
| Evening reminder toggle title | "Evening reminder" |
| Evening reminder subtitle (off) | "Opt-in reminder to close your day" |
| Evening reminder subtitle (on) | "8:00 PM" (via `_formatMinutes(1200)`) |
| Evening notification body | "Time to close the day. See how your chunks went." |
| Evening notification title | "Canopy" (matches morning notification pattern) |

**Tone:** Warm, first-person plural avoided. "How did today go?" is neutral and
inviting — not evaluative ("You completed X%"). The summary screen is the place
for numbers; the card is the invitation.

**Source for "X of Y chunks done" pattern:** `end_of_day_summary_screen.dart` line 79
(`'of $total chunks complete'`). Card subtitle mirrors this language but uses simpler
"done" to match the card's lighter register.

**Deferred ideas (do not add):** Congratulatory copy variants, streak celebration
messages, dynamic copy based on mood — all deferred per CONTEXT.md.

## Interaction Contract

### End-of-Day Card Appearance

| State | Visual |
|-------|--------|
| Trigger not met | Card not rendered (no space reserved) |
| Trigger met, not dismissed | Card visible at top of active-schedule view |
| Dismissed (in-session) | Card not rendered; state held in `bool _eodCardDismissed` |
| App relaunched, trigger still met | Card reappears (same as quarterly review banner) |

### Dismiss Gesture

- Swipe left or right: `Dismissible` wraps the card, `DismissDirection.horizontal`,
  `onDismissed: (_) => setState(() => _eodCardDismissed = true)`.
- Tap X button: same state mutation without animation.
- No confirmation required for dismissal — the summary screen remains accessible
  via the Schedule tab's existing route if the user changes their mind.

### "Close the day" Button

- `ElevatedButton` inside the card.
- On tap: `context.push('/summary')`.
- No loading state needed — `EndOfDaySummaryScreen` reads synchronously from Provider.
- Button remains tappable after the screen is dismissed via back navigation — the card
  persists until the user explicitly dismisses it.

### Evening Reminder Toggle

- `Switch` widget; default value: `false` (opt-in per CONTEXT.md).
- `onChanged(true)`: call `SettingsNotifier.setEveningReminderEnabled(true)` then
  `NotificationService.scheduleEveningReminder(1200)`.
- `onChanged(false)`: call `SettingsNotifier.setEveningReminderEnabled(false)` then
  `NotificationService.cancelEveningReminder()`.
- No confirmation dialog — toggle is non-destructive.
- Desktop/Web guard: mirror the `zonedSchedule` guard pattern from
  `scheduleMorningNotification` (notification id 2).

## Accessibility

- End-of-day card dismiss `IconButton`: `tooltip: 'Dismiss'` — required for
  screen readers. `semanticLabel` on the icon is not needed when `tooltip` is set.
- "Close the day" `ElevatedButton`: label is already semantic; no additional
  annotation needed.
- `Dismissible` swipe: the redundant close `IconButton` ensures the dismiss action
  is accessible without gesture — matches the `ReviewBanner` pattern.
- Color contrast: all text uses `onPrimaryContainer` or `onSurfaceVariant` over
  `primaryContainer` — Material 3's contrast guarantee holds for all five mood seeds.
- Evening reminder `Switch`: `ListTile` semantics automatically combine title +
  trailing widget into an accessible toggle — no manual `Semantics` wrapping needed.
