<objective>
Create the three-file conditional-import trio that lets the desktop-only `window_manager` package be safely imported in `lib/main.dart` without breaking Web builds. This is the standard Dart `dart.library.io` idiom: a re-export entry, a real desktop implementation, and a web stub.

Output: Three new files under `lib/platform/`. The same `setupDesktopWindow()` symbol is exposed by both io and stub files; `main.dart` (modified in Plan 04) imports only `window_setup.dart` and gets the right body per platform at compile time.
</objective>

  import 'package:flutter/material.dart' show Size;
  import 'package:window_manager/window_manager.dart';
  Future<void> setupDesktopWindow() async {
    if (kIsWeb) return;
    if (!(Platform.isWindows || Platform.isMacOS || Platform.isLinux)) return;
    await windowManager.ensureInitialized();
    await windowManager.setMinimumSize(const Size(480, 640));
  }
