<objective>
Create the single source of truth for app-wide color identity: a `ThemeNotifier` that holds the user's current mood seed (or null = "curious" pre-check-in), modulates the seed by time of day using HSL math on a 20-minute cadence (with lifecycle-aware pause/resume), persists the seed to Hive, and resets to curious at daily rollover.

Purpose: D-01 / D-02 require app-wide mood theming via `ColorScheme.fromSeed` at the MaterialApp level. ThemeNotifier is the ChangeNotifier that drives that scheme. D-04/D-05/D-06 specify time-of-day modulation. D-07 specifies the curious pre-check-in state. D-10 forbids carry-forward across days. AC-6 requires the seed change to be visible within 600ms (achieved at Plan 04 via `themeAnimationDuration: 500ms`).

Output: `lib/providers/theme_notifier.dart` with the full ChangeNotifier class plus the static `moodSeeds` map and `curiousSeed` constant. No app wiring yet — Plan 04 owns the wiring into MaterialApp.router.
</objective>
