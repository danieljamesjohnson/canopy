<objective>
Persist `syntheticStartMinutes` so discretionary-chunk clock times survive an app restart, and add a unified `displayStartMinutes` accessor. This is the data-layer foundation for SCHED-01; the schedule-card and Home plans (12-02, 12-03) read clock times through `displayStartMinutes` and depend on this field being persisted.

Purpose: Today the generator computes `syntheticStartMinutes` in memory but it is transient (no `@HiveField`), so after a relaunch discretionary chunks lose their clock time. Persisting it as `@HiveField(10)` with an additive no-op migration to schema version 7 fixes this without any data transformation.

Output: `@HiveField(10) int? syntheticStartMinutes` on `ScheduledChunk`, a `displayStartMinutes` getter, regenerated Hive adapter, `_migration6to7` no-op, `currentSchemaVersion = 7`, and a regression test.
</objective>
